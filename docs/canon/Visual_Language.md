# Visual Language Bible — Elyndor

The project's **art-direction handbook**: the shared visual rules that keep every
character, prop, and environment feeling like the same world. This document
defines *visual principles only*. It does **not** author lore or gameplay —
unknown specifics use `_TBD_`. Anchored by the two production examples, **Talos**
(discipline / steel) and **Eleanor** (hope / light).

---

## 1. Overall Style
- **Stylized fantasy** — grounded realism with a hand-crafted, painterly finish;
  not photoreal, not cartoon.
- **Readable silhouettes** — every subject must be identifiable in pure black
  silhouette. Silhouette beats detail.
- **Grounded realism** — believable materials, proportions, and wear; fantasy
  elements feel physically present.
- **Bright but believable colours** — saturated where it matters, never garish;
  value contrast carries readability.
- **High readability from an isometric/near-iso camera** — design for the
  gameplay viewing angle and distance first; top-down legibility of shapes,
  colours, and key props is mandatory.

## 2. Armour
| Type | Visual rule |
|---|---|
| Light armour | Cloth + light leather; agile silhouette; minimal metal; freedom of movement reads. |
| Medium armour | Leather + mail + partial plate; balanced bulk; practical, layered. |
| Heavy armour | Full plate; broad, weighty silhouette; discipline and mass (see **Talos**). |
| Mage clothing | Flowing layered robes; light protective leather; elegant, travel-ready (see **Eleanor** — not fragile, not bulky). |
| Travel gear | Straps, pouches, boots, cloaks; utilitarian; signs of the road. |
| Ceremonial attire | Refined, symbolic, ornamented; faction/house identity foregrounded. _Specifics: TBD._ |
| Civilian clothing | Simple, regional, class-appropriate; low ornamentation. _Specifics: TBD._ |

## 3. Weapons
Visual philosophy — form communicates function and owner.
| Weapon | Philosophy |
|---|---|
| Swords | Balanced, honest lines; the "default" martial read (see **Talos**' longsword). |
| Axes | Weight-forward, brutal mass; splitting intent. |
| Polearms | Reach and control; long clean silhouettes. |
| Bows | Elegant tension; light, precise. |
| Daggers | Small, quick, concealable; rogue identity. |
| Mage staffs | Refined channeling focus, crystalline/gem headpiece; graceful, not martial (see **Eleanor**'s golden crystal staff). |
| Shields | Defensive statement; a natural canvas for heraldry/iconography (see Talos' sun sigil). |

## 4. Materials
| Material | Visual characteristics |
|---|---|
| Steel | Cool gunmetal, crisp specular highlights, hard edges. |
| Iron | Darker, matte, rougher than steel; utilitarian. |
| Bronze | Warm brown-gold, soft sheen, patina in recesses. |
| Gold | Bright warm reflectance, soft highlights, prestige. |
| Leather | Matte, supple, subtle grain; light-brown default. |
| Wood | Visible grain, warm mids, worn edges. |
| Cloth | Soft folds, low specular, colour-carrying. |
| Rare metals | Pale-gold/luminous alloys, tarnish-resistant, gentle sheen (e.g. the Hearthstone Pendant metal). |
| Crystal | Faceted, translucent, internal light; cool gem hues. |
| Stone | Rough, matte, heavy; weather and age. |

## 5. Magic (visual principles only)
- **Elemental effects** read by colour + motion: fire = warm oranges/reds, rising;
  frost = pale blue/white, crystalline; shadow = desaturated dark, dissolving.
- **Light** is a core theme — hopeful characters carry warm light (see Eleanor).
- **Particle density** stays legible: enough to sell the effect, never enough to
  obscure the silhouette or the tactical read.
- **Colour usage** signals intent (see §7); keep friendly/hostile magic
  distinguishable at a glance.
- **Silhouette readability** — spell VFX must not swallow the caster or the grid.
- _No gameplay/mechanics are defined here._

## 6. Character Shapes (silhouette philosophy)
| Archetype | Silhouette |
|---|---|
| Knights / Guardians | Broad, grounded, heavy; vertical mass and hard shoulders. |
| Mages | Flowing, tall, softer; robe movement and a focus in hand. |
| Rogues | Lean, low, angular; hoods, wraps, hidden lines. |
| Hunters / Rangers | Athletic, layered travel gear, bow silhouette. |
| Support | Approachable, open posture, readable "helper" shapes. |
| Large creatures | Dominant mass, exaggerated proportions, unmistakable footprint. |
| Small creatures | Compact, quick, low to the ground; readable in groups. |

## 7. Colour Language (what colour communicates)
| Meaning | Colour direction |
|---|---|
| Hope | Warm ivory/gold + emerald + soft blue (see **Eleanor**). |
| Danger | Hot reds, harsh contrast. |
| Corruption | Sickly greens/violets, desaturated rot. |
| Royalty | Deep purples, gold, rich saturation. |
| Nature | Earthy greens/browns, organic. |
| Magic | Luminous cools (blue/teal) or element-coded hues. |
| Faith | Radiant whites/golds, clean light. |
| Death | Bone/ash greys, cold desaturation. |
| Unknown areas | _TBD — placeholder until established._ |
