# Character Production Checklist (reusable)

Copy this block per character (e.g. into their canon entry or a tracking issue).
Tick items only when the deliverable actually exists. See
[`../Character_Production_Bible.md`](../Character_Production_Bible.md) for what
each item means and [`../Character_Production_Status.md`](../Character_Production_Status.md)
for the live roster.

## <Character Name> — Production Checklist

**Foundation**
- [ ] Lore complete (`docs/heroes/`, `docs/characters/`)
- [ ] Canon documentation (`docs/canon/Characters.md` entry)

**Reference art**
- [ ] Hero sheet
- [ ] Full body render
- [ ] Turnaround sheet
- [ ] Colour palette locked
- [ ] Equipment reference
- [ ] Weapon reference
- [ ] Facial expression sheet

**3D pipeline**
- [ ] Tripo (model generated)
- [ ] Blender cleanup (retopo, UVs, materials)
- [ ] Rigging
- [ ] Godot import

**Animation**
- [ ] Idle animations
- [ ] Combat animations

**Delivery**
- [ ] UI portrait
- [ ] Marketing render
- [ ] Voice direction / VO
- [ ] Revision logged

**Gate:** *Reference Complete* = foundation + reference art (minus Tripo) done.
*Production Complete* = all boxes ticked.
