# Lore Bible

This folder contains the canonical worldbuilding for the RPG. Any future content — quests, dialogue, codex entries, NPCs, companions, systems, and story events — must remain consistent with these documents.

If a future idea contradicts anything written here, **these files take precedence** until they are intentionally revised. A revision requires a deliberate decision, not a workaround.

---

## How to Use This Folder

Read `CANON_RULES.md` first. It contains the immutable principles that govern all design decisions. Nothing in this folder or in any other document overrides those rules.

## Authorship Note

These documents were established during the core design phase of the project. The principles they contain are not suggestions — they are the design decisions the entire game is built around.

Writers, systems designers, and AI sessions should consult this folder before introducing any new faction, historical event, divine intervention, or canonical claim about how the world works.
