# Playable Characters — Tactical RPG

> This section contains character sheets for all playable characters and companions in the Tactical RPG.  
> These are **game-specific documents**. They belong here, not in the Elyndor Universe Bible.  
> Ancient Legends (Aurelia Sunstrider, Valen Ashfall) belong in `elyndor/ancient_legends/`.

---

## Character Categories

| Category | Location | Examples |
|---|---|---|
| Playable characters & companions | `docs/characters/` (here) | Talos, Eleanor, Ragash, Ronan, Steven |
| Ancient Legends / mythological figures | `elyndor/ancient_legends/` | Aurelia Sunstrider, Valen Ashfall |

**Never place playable characters in the Universe Bible. Never place Ancient Legends in this folder unless a future story explicitly makes them playable.**

---

## Adding a New Character

1. Copy `_character_template.md`
2. Name the file `<firstname_lowercase>.md`
3. Fill in all known fields — leave unknown fields blank, not removed
4. Add the character to the roster table below

## Game Tone

The overall tone of this game is a mix of **dark fantasy and adventure** — serious enough to take the world's dangers at face value, with enough warmth and humanity to keep it from becoming oppressive. See [`../game_tone.md`](../game_tone.md) for details.
