# Design Standards — Folder Index

> **Canon Status:** Confirmed — established July 2026.
> **Authority:** This folder holds the project's binding design standards. All new features and content must comply with them. Canon content itself lives in [`docs/lore/`](../lore/), [`docs/world/`](../world/), and [`elyndor/`](../../elyndor/) per [`docs/lore/CANON_RULES.md`](../lore/CANON_RULES.md).
