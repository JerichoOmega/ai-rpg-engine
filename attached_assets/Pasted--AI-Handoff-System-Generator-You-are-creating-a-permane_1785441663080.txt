# AI Handoff System Generator

You are creating a permanent AI handoff system for this repository.

This is not a changelog.

This is not documentation about the game.

This is a standardized communication system that allows one AI assistant or developer to hand work off to another without losing context.

Future contributors should:

Read the most recent handoff first.

Then read:

PROJECT_MEMORY.md

PROJECT_STATE.md

PROJECT_CONSTITUTION.md

GAME_BIBLE.md

AI_CONTINUATION_GUIDE.md

before beginning development.

At the end of every significant development session:

Create a new dated handoff document.

Never overwrite previous handoffs.

Treat handoffs as a historical record.

QUALITY REQUIREMENTS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

The handoff system should:

Be concise enough to read in a few minutes.

Contain enough detail that another AI can immediately continue development.

Cross-reference existing documentation rather than duplicate it.

Clearly distinguish:

Completed

In Progress

Blocked

Planned

After generating the handoff system:

Verify all links.

Update PROJECT_MEMORY.md to mention the handoff process.

Update PROJECT_STATE.md to reference the latest handoff.

Update AI_CONTINUATION_GUIDE.md to instruct future AI assistants to begin each session by reading the newest handoff document.

Ensure the handoff system complements the existing documentation suite without creating duplicate sources of truth.

The goal is to create a permanent development history that preserves context between AI assistants and human developers while keeping the repository organized and easy to maintain.
