# Elyndor Universe Bible

## Purpose
Elyndor is a reusable fantasy universe independent of any single game.

This repository preserves the world's lore, mythology, creatures, and historical figures.
Gameplay systems are intentionally excluded.

## Canon Rules
- The world is called **Elyndor**.
- Geography is intentionally undefined.
- There is no fixed number of continents, kingdoms, or nations.
- Future projects may define these as needed.
- Ancient Legends are historical or mythical figures from a forgotten age.
- Modern protagonists belong to their own game's cast and are not part of the Ancient Legends by default.
